## O que é / What it is

Um mod simples que permite personalizar o intervalo do limpador de RAM do SPT, com opção de limpar apenas durante raids e um botão de limpeza imediata.

A simple mod that lets you customize the SPT RAM cleaner interval, with an option to only clean during raids and a clean now button.

## Funcionalidades / Features

| Funcionalidade | Descrição |
|---|---|
| **Intervalo personalizável** | Define o intervalo entre limpezas de 30 a 900 segundos (padrão: 300s) |
| **Botão "Clean Now"** | Executa a limpeza de RAM imediatamente |
| **Apenas em raid** | Opção para executar a limpeza apenas durante raids |
| **Configuração F12** | Todas as definições acessíveis via F2 → BepInEx Config |

| Feature | Description |
|---|---|
| **Customizable interval** | Set cleaning interval from 30 to 900 seconds (default: 300s) |
| **Clean Now button** | Execute RAM cleaning immediately |
| **Only in raid** | Option to only run the cleaner during raids |
| **F12 config** | All settings accessible via F2 → BepInEx Config |

## Instalação / Install

1. Download do ZIP em Releases.
2. Extrai para `BepInEx\plugins\` (fica `SPT-RamCleanerInterval-SPT.4.0.13\`).
3. Corre o SPT.
4. Pressiona F2 no menu principal → BepInEx Config para configurar.
