# DayTimeCultists — SPT Mod

**Version:** 1.2.0
**Author:** p-kossa (original)
**SPT Version:** 4.0.13
**License:** MIT

---


DayTimeCultists adjusts cultist spawn behavior to only occur during nighttime hours, making the game more realistic and balanced. Cultists will no longer spawn during daylight raids.

### Features

- Cultists only spawn at night (configurable hours)
- Configurable spawn window (default: 21:00 - 06:00)
- No more daytime cultist encounters
- Works with all maps that support cultist spawns

### Configuration

Edit the config in `BepInEx/config/com.DayTimeCultists.cfg`:

| Setting | Default | Description |
|---------|---------|-------------|
| `Enabled` | `true` | Enable/disable the mod |
| `NightStartHour` | `21` | Hour when night starts (24h format) |
| `NightEndHour` | `6` | Hour when night ends (24h format) |
